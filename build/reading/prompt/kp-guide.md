# 考点讲解稿 · 生成规范

> 版本：2026-11-18 **v3**｜用于 `build/reading/talk/*.md` 的批量生成
> v1 六段式：铺垫太多、字数虚高 → 废弃。
> v2 纯矩阵：铺垫砍光，密度拉满，**听不下去** → 也废弃。
> v3 = **分层铺垫 + 矩阵考点**。铺垫要的是「为什么」，不是「是什么」。

---

## 一、核心判据：铺垫的厚度必须分层

密度不是越高越好。听众没有屏幕、不能回看、不能暂停思考，
所以**必须给理解留台阶**。但台阶不能每一级都修成平台。

| 层 | 讲什么 | 厚度 | 判据 |
|---|---|---|---|
| **A 已知道的** | 数组连续、指针是地址、栈是后进先出 | **一句**，不解释 | 说了听众不会"哦原来如此" |
| **B 需要动机的** | 为什么有这个东西、为什么加这个部件、为什么有这种变体 | **3–5 句**，必须有「没有它会怎样」的对照 | 说了听众会"原来是这么来的" |
| **C 往后接的** | 它通向哪儿（线索树、树、图、邻接表、B+ 树） | **1–2 句**，只点不展开 | 说了听众会"后面还会遇到" |
| **D 考点** | 具体操作要关注什么 | 主体 | 说了听众能做题 |

**判定**：如果一段铺垫里全是 A 层，删到一句；如果全是 D 层，中间没有 B 层台阶，听众会掉队。

### B 层的唯一判据：这段能不能从教材定义里抄到？

能抄到的，删掉或改写。铺垫要回答的是**「这条知识在题里省掉哪一步」**，不是「它是什么」。

**反例（定义复述，零信息，一律删）**

- 「奇偶讲的是一种对称：把自变量的位置从原点左边换到右边，函数值只允许原样不变或只翻一个符号」
- 「有界从来不是函数自己的属性，是函数在某一段上的属性」
- 「事件就是一个集合，于是运算就是集合运算」
- 「为什么奇偶的第一道关是定义域」—— 接下来讲的仍然是「定义域为什么要对称」，还是定义

**正例（落到具体题型，说清省了哪一步）**

- 「对称区间上积分，奇部直接为零、偶部翻倍——这一步省掉整道题一半的计算」
- 「傅里叶系数里奇函数只有正弦项，余弦系数为零，少算一半」
- 「奇函数若在原点有定义，那一点的值必为零，能直接定参数」
- 「有界是收敛的必要条件，所以证发散先证无界，比算极限快」

**每条性质/概念至少给两处「用在哪」**。只给出一处的，说明它还不够重要，压成一句带过。

**禁止清单**

- 名词解释、定义复述、性质罗列（「奇偶有三条性质：…」）
- 「这是很重要的概念」「需要重点掌握」这类评价
- 以「为什么」开头但内容仍是定义（最常见的一种伪装）

### B 层的标准问法（每条 3–5 句，都要能回答）

- **为什么有它**：原来的做法在哪件事上做不到 → 它把哪个前提去掉了 → 代价是什么
- **为什么加这个部件**：没有它的时候，哪些情况要特判 → 加上之后为什么统一了
- **为什么有这种变体**：基础版在什么场景下不够用 → 变体补了哪一块

### C 层只点不展开

允许多点几个方向（树、图、线索树、B+ 树），但每个**一句**，不解释机制。
作用是让听众知道"这块还没完"，不是提前上课。

## 二、结构（五段，顺序固定）

### 第 1 段 · 铺台阶（400–700 字）

按 B 层问法讲**为什么**，一般两到三个"为什么"。每一问答 3–5 句。

可以包含：
- 为什么有这个东西（原来的做法哪件事做不到）
- 为什么加头结点 / 哨兵 / 尾指针这类部件
- 为什么有循环、静态、链式这类变体
- 它用在哪（一两句，具体到名字）

**不讲**：教科书定义、历史、谁发明的、考试怎么考。

### 第 2 段 · 往后接（60–150 字）

一到三句，指向后面的内容。只点方向，不给机制。

例：
> 这条线往下走就是线索树——把那些空指针利用起来，直接指向前驱后继，省掉反复走链。
> 再往后，图的邻接表其实就是"链表的数组"，一个链表存一个顶点的所有邻居。

### 第 3 段 · 摆矩阵（100–200 字）

- 分类：几个，每个**一句**说清它比基础版多了或少了什么
- 功能：几个，每个**一句**
- 一句结论：这么多格里只有几格不一样，考试考那几格

### 第 4 段 · 哪几格不一样（400–600 字，主体）

先给一句**原则**，概括为什么大部分格子答案相同。
再逐格讲差异，每格不超过 120 字，句式：

```
<分类> 做 <功能>：能 / 不能，代价多少。
为什么：<一句因果>。
```

### 第 5 段 · 坑与边界（150–250 字）

- 坑 3 条以内，每条一句「错在哪 + 为什么会错」
- 边界一句：什么时候不适用（退化、和谁容易混）

不写「总结」「小结」。

---

## 三、主题（写在稿子第 2 行）

一句话，指明「差异的来源是什么」。例：

| KP | 主题 |
|---|---|
| 链表 | 所有差异来自有没有一条直接指向前驱的边 |
| 顺序表 | 所有便宜来自连续，所有代价也来自连续 |
| 顺序表扩容 | 单次贵，摊还便宜 |

第 4 段的每一格都必须能挂回主题。

---

## 四、语言

### 要

- **第二人称**：「你手上只有当前结点」
- **短句**，一句一件事
- **具体数字**：不是「移动很多」，是「平均 n 除以 2 个」
- **对照**：「没有它会怎样」必须显式说出来
- **判断句**：「这个不行」「这一格是考点」

### 不要（这些是废话，不是铺垫）

- 评价：`非常重要`、`这是高频考点`、`需要重点掌握`、`众所周知`、`显然`
- 空转：`先说好消息`、`你可能会想，这不就是背选项吗`、`很多人以为很简单`
- 复述：同一个意思换句话讲两遍
- 罗列超过三项：`第一…第二…第三…第四…`，超过三个改成叙述
- 括号补充：朗读时括号是噪音

**注意**：「为什么有链表」这类**是真铺垫，不算废话**；
「你可能会想这不就是背选项吗」是**空转**，因为不给任何信息。

### 只讲角色，不讲符号

禁止：单字母变量名（`p` `q` `s` `h` `L` `cur` `tmp`）、「第 N 题」、选项字母（A/B/C/D）、
复述代码行、朗读代码片段。

改写成角色：头结点 / 尾指针 / 待删结点 / 新结点 / 临时指针 / 前驱 / 后继。
结构字段（`next`/`prev`/`data`）可说一次，之后用「后续指针」。

真题不念题面，还原成「给定什么状态 + 要达成什么 + 关键卡在哪」。

## 五、公式与符号

| 原写法 | 朗读写法 |
|---|---|
| `$O(1)$` | `O 1` |
| `$O(\log n)$` | `O log n` |
| `$n/2$` | `n 除以 2` |
| `$n-i+1$` | `n 减 i 加 1` |
| `$A^{T}$` | `A 转置` |
| `$r(A)$` | `A 的秩` |
| `$|A|$` | `A 的行列式` |
| `$P(A\mid B)$` | `在 B 发生条件下 A 的概率` |

**绝不出现**：`$`、反斜杠、下划线、竖线、`{}`。

## 六、事实约束

| 类别 | 来源 | 允许扩写 |
|---|---|---|
| 考纲要求（A/B 级）、标签（常考/高频） | **`syllabus/408.md`** 该 KP 那一行 | 否，逐字用 |
| 真题落点（哪年哪场） | 源 note 的首行引用块 | 否，且**不写题号** |

> ⚠ 注意分工：`note/408/**` 里**没有** A/B 级字样（它只写「档位：掌握」），
> 等级与标签只存在于 `syllabus/408.md` 的表格列里。写稿时两处都要读。
| 考法与陷阱 | 源 note 的「思路 / 坑」段 | 可重组、可讲开，**不可新增** |
| 动机与应用 | 通用领域知识 | 可新增，须常见且正确 |
| 后续方向（C 层） | 通用 | 可新增，须确实是后续章节的真实内容 |

**禁止**：编造真题题号、编造数字结论、编造「某教材说」。

## 七、长度

- **1000–2000 字**，按「分类 × 功能」的格数分档：
  - 单类、功能少（顺序表 1×5）：**1000–1300 字**
  - 多类、多格（链表 4×5、树的六类×四功能）：**1500–2000 字**
  - 硬凑字数会灌水，短不是问题，铺垫缺了才是问题
- 铺垫（第 1–2 段）约占 1/3，考点（第 3–5 段）约占 2/3
- 超过 2000 字先砍重复句，不要砍铺垫
- 段落不超过 4 行

## 九、验收（reviewer 逐条打勾，任一不过退回）

1. 第 1 段至少回答**两个「为什么」**（为什么有它 / 为什么加那个部件 / 为什么有变体）
2. 每个「为什么」都有「没有它会怎样」的对照
3. 第 2 段指向后续内容，1–3 句，只点不展开
4. 第 3 段把分类与功能列清，一句结论指出只有几格不一样
5. 第 4 段有**一条原则** + 逐格差异，每格 ≤120 字
6. 主题写在第 2 行，第 4 段每格能挂回
7. 无单字母变量、无题号、无选项字母、无代码片段
8. 无空转句（`先说好消息`/`你可能会想`/`非常重要`/`众所周知`）
9. 无 `$`、反斜杠、下划线、竖线、花括号
10. 1500–2000 字，铺垫约占 1/3
11. 第 5 段收尾，没有「总结一下」
