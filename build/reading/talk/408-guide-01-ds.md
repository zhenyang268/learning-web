# 数据结构这一科到底在考什么

> 讲解稿｜源：`notebook/kaoyan/syllabus/408-guide.md` §一（数据结构）

## 一句话的职责

数据结构这一科，一句话概括它的职责：把一份按位置排好的数据，变成好几份能在给定代价之内被找到、被增删、被排序的数据组织。

注意这里有个词很关键，叫给定代价。什么叫给定代价？就是你不能只说"这个能查到"，你得说"这个查一次要花多少钱"。

它挡的是一个很具体的问题：同样一堆元素，换一种存法，某一类操作的价格就换一个量级。注意是量级，不是差个百分之几十。顺序表随机访问是常数时间，链表随机访问就得从头一个个走；反过来，链表插一个结点只是改两个指针，顺序表在中间插一个就要把后面的一批元素整体挪位。

所以这一科不生产数据，它生产的是代价表。你学完每一章，手里应该多一张表：这种结构，哪种操作便宜，哪种操作贵，贵到什么程度，什么情况下会突然变贵。考试考的是这张表算得对不对，工程里选的是这张表用不用得对。

## 六块：每种结构在换什么代价

整科可以切成六块，每一块都在回答同一个句式的填空：一份什么东西，变成多份什么东西。

**A 块，地址算术。** 一份连续的下标空间，变成多份"第 i 个在哪"的算术。顺序表、数组、多维矩阵都在这块。它的使用面有三条：第一，常数时间随机访问的根据是什么，就是那条地址公式；第二，插入删除的平均移动量怎么算；第三，多维矩阵摊平成一维的时候，偏移量怎么换算。

判据很硬：算地址、算移动次数，公式错一位就全错，不是扣一半分的问题。

**B 块，链式改写。** 一份用指针串起来的记录，变成多份可以局部重排、不用整体搬家的结构。单链表、双链表、循环链表、静态链表，还有并查集都在这一块。

它的使用面是：改指针的顺序合不合法，边界情况有没有考虑，以及逆置、合并、快慢指针这几类经典写法。判据是要你手写 C 的结构体加指针，阅卷看的是会不会断链、边界有没有漏。

这里补一句最容易失分的地方：链表题不是考你会不会写，是考你改指针的顺序。你得先说清楚先接后继还是先断前驱，顺序反了链就断了。

**C 块，受限容器。** 一份线性序列，变成多份被禁止了某些访问方式的子集。栈只允许一端进出，队列只允许一端进另一端出，双端队列两端都行。

使用面三条：单端可动还是双端可动；判空判满的约定是什么；还有一类特别爱考的手算题，出栈序列有多少种。

判据是手算序列：出栈合法性、中缀表达式转后缀、循环队列的下标运算。这些题都是纸笔算，算错一步后面全错。

**D 块，序上的搜索。** 一份带偏序关系的结点集，变成多份对数级、可以手算的查找路径。二叉树、线索二叉树、哈夫曼树、折半查找、二叉排序树、平衡树都在这一块。

使用面三条：给遍历序列能不能把结构还原出来；判定树怎么推出平均查找长度；以及那个不变量是怎么把树高压到对数级的。

判据是还原序列、算平均查找长度——注意成功和失败是两个分母，别用混——还有画旋转。

**E 块，最优性。** 一份带权图，变成多份按不同目标函数取的极值。最小生成树求总权最小，最短路径求两点距离最小，拓扑排序求一个合法顺序，关键路径求工期。

使用面：按点扩展还是按边选边；表格法逐轮怎么定标；以及顶点量级的算法和边量级的算法分别是什么。

判据是手算逐行。这块最忌讳跳步，因为跳过去的那一步，恰好就是判据本身。

**F 块，全序化。** 一份乱序的记录集，变成多份按关键字排好的序列。八大排序、外部排序都在这。

使用面：一趟排序之后的中间状态长什么样；时间空间稳定性的对比；外部排序的磁盘读写次数怎么算。

判据是反查——给你一趟的结果，问你是哪个算法排的；算趟数、算读写次数、判断稳定性。

## 两条线：串起六块的那根绳

六块之间不是并列的六堆知识，有两条线把它们串起来。

第一条叫代价账，这是最强的一条。你回头看六块，每一块都在答同一个问题：这个操作要花多少钱。顺序表付的是移动，链表付的是指针，树付的是高度，堆付的是下沉，散列付的是冲突，外部排序付的是磁盘读写。

所以这是整科唯一的统一语言。以后遇到一个新结构，你先问一句：它把哪一项代价换成了哪一项。答上来了，这个结构你就懂了。

第二条叫最坏情形。退化是这一科的主线：二叉排序树在有序输入下退化成一条链，快排对基本有序的输入退化到 n 的平方，顺序表在头部插入退化成搬整张表。

六块每一块都有一个"前提一破，价格就变"的失效点。这条线和操作系统那边是接得上的——系统侧看极限也是取最坏。

还有一件事要交代清楚：并发一致性和故障恢复这两条线，在数据结构这一科里面是空的。为什么？因为单机单线程，不会出现两个持有者同时改一份状态的情况。唯一的越科接口是"优先级就绪队列用单链表实现"这类缝合题，那本质上是操作系统的调度代价，不是数据结构的内容。

## 考试怎么问，工程怎么问

最后说一个很多人忽略的差别：同一块知识，考试和工程问的是两件事。

考试问的是，给你一个小规模实例，手算一个数字或者一条序列出来。三个元素排序、五个顶点的 Dijkstra 表格、七次查找的平均查找长度。

判据是和标准答案逐位相同。所以中间记号必须跟题干约定一致——下标从 0 还是从 1，平均查找长度的分母是 n 还是 m。这一科考的就是在有约定的小世界里走完一步不失手。

工程问的是另一套：给你规模、负载形状、还有一个约束，比如内存上限、必须稳定、数据在外存，然后问你选哪个结构，它在什么输入上会塌。

判据是能不能预测退化。你选快排，得说清哪种分布把它打成 n 的平方；你选哈希，得说清装填因子到多少的时候平均查找长度就失控了。

所以一句话收尾：考试问算得对，工程问选得对而且知道什么时候不对。
