# 数项级数判敛：先给通项分个类，再看它衰减多快，拿一把刚好量得出的尺子去比
> 讲解稿｜源：`notebook/kaoyan/note/math1/hs/M1-HS-0701-数项级数判敛.md`｜主题：判敛的全部动作是「找一把已知命运的尺子去比对」，通项结构决定尺子的精度，符号结构决定要不要先拆绝对值，而尺子量出的比值恰好等于一时它就没用了

## 为什么这件事只能靠比

无穷多项加起来，你没法真的加完，「和是多少」这条路从一开始就堵死。退一步，问题变成「它到底有没有上限」。

这个答案不看前面有限多项，只看足够靠后的项衰减得够不够快。要让「够不够快」有意义，必须有参照物——于是问题从「求一个数」变成「跟一个已知命运的级数比大小」。后面所有判别法，都是在造参照物。

**为什么第一把尺子是方幂族。** 等比家族很好用，但它要求每项与上一项的比值固定；现实里通项的比值是变动的，多半根本写不出一个固定倍数。方幂族把这个限制去掉了：通项是 n 的负若干次幂，指数大于一就收敛，小于等于一发就散。代价是这条界线不来自求和公式，来自连续化之后算的那块面积——指数大于一时那块面积有限，等于或小于一时无限。

**为什么比值法和根值法只在特定结构上出现。** 分式、根号、多项式之比，都能抓最高阶化成负次幂，方幂族就够用。可一旦通项里出现阶乘、出现一长串连乘、出现 n 的 n 次方这种幂指同体，抓最高阶这一步就卡住了——阶乘既不是幂也不是多项式。相邻两项一除，阶乘约掉、连乘约掉；整块 n 次方开一次根，指数散掉。这两个办法不是新原理，是把通项先化简成能读阶的样子。代价是它们只回答「比一大」还是「比一小」，恰好等于一就什么都不说。

**为什么必须先分类，再谈判别。** 因为符号结构决定工具完全不同。通项最终恒为非负的，走比大小那一套；符号整齐交替的，正负互相抵消，大项也可能收敛，比大小失去意义，要先拆绝对值再看原级数；符号是某项三角函数那样乱摆的，它根本不逐项变号，按交错处理会直接给出错答案。分类定错，后面所有计算都白做。

## 往后接到哪

再往下一层，是幂级数：把通项换成一个带变量的形式，判敛就变成求收敛半径。

再往后，收敛域端点上的讨论会回到这里，用的还是同一批尺子。

## 五类问法与一句共用的判断

两件事先分清：通项最终是不是恒非负，以及它衰减的阶是多少。

五类问法：分式或根号之比用比较、整块多次方用开根、含阶乘或连乘用相邻之比、单调且能写成可积函数用积分判别、符号整齐交替用莱布尼茨。

原则一句话：整张表只有一处是分水岭——把通项读成一个「负若干次幂」，指数与那个一比，大了收敛，小了发散，恰好相等就得换更细的工具。

## 哪几格不一样

**分式、根号、多项式之比：抓分子的最高阶和分母的最高阶。** 能，代价是那个常数要一起带上，根号里的最高次幂还要开方，指数容易少写一半。为什么：只读阶不读常数，会漏掉同阶这一种情形。用在哪：通项形如系数除以 n 的一次幂时，它跟调和级数同命运，而调和级数是发散的。

**同阶不等于收敛，同阶只等于同命运。** 为什么：极限比较给出的结论是「跟那把尺子一起生或一起死」，而指数等于一的那把尺子本身就是发散的。

**通项带对数：方幂族读不准了。** 对数比任何正次幂都弱，它不改变敛散，却会把指数读偏。为什么：像 n 的一次幂乘对数的倒数这种东西，按方幂族读成指数等于一，结论正好反了。这时候要么直接积分，要么把它夹在两条方幂之间。

**通项含阶乘、连乘、整块 n 次方：用相邻之比或开根。** 能，代价是算出恰好等于一时它失效。为什么：这两把尺子只比较相邻，判据的结论全部落在「与一比」上，等于一意味着量不出差别，必须换。

**通项单调且能写成某个可积函数：用积分判别。** 能，代价是三条前提要逐条验——某个位置之后为正、连续、单调不增。为什么：三条齐全才能把求和与积分绑在一起；题给的通项完全可能前几项来回晃，直接积分就把前提偷偷用掉了。

**符号整齐交替：先拆绝对值，再谈交错。** 能，代价是多一步。为什么：绝对值级数收敛，直接定为绝对收敛，整题结束；绝对值发散才回到原级数，验「绝对值单调不增」和「通项趋于零」两条，两条都过才叫条件收敛。用在哪：通项是交替号乘 n 的一次幂的倒数时，绝对值那一支是调和级数、发散的，回到原级数才判出收敛，于是它是条件收敛而不是绝对收敛。

**交错那两条是并列的，不是一条。** 趋于零只是必要条件。为什么：单调性漏掉，答案就只剩一半，这是最典型的半截答案。

**符号乱摆的：一律按任意项处理，先查绝对值。** 为什么：有一种看起来像交替的符号，其实是四项一个循环，走的是正、零、负、零，根本不逐项变号，套交错判据必然错。

**绝对收敛与条件收敛不是一回事。** 为什么：前者强，后者只在原来的符号下成立；把条件收敛写成绝对收敛，等于用了一个没验证过的更强的结论。

## 三个坑，一句话边界

坑一，只验证通项趋于零就宣布交错级数过关。错在那是必要条件，单调性漏了，答案只有一半。

坑二，比值或根值的极限恰好等于一，顺手写个收敛。错在等于一说明这把尺子量不出差别，必须换更细的。

坑三，拿小的去比大的。错在比较的方向决定结论的方向，基准选错，答案整个反过来。

边界：这一整套是给最终恒为非负的通项准备的，符号一变就先拆绝对值；积分判别只能用在单调那一档上，否则求和与积分不同命运。
