单调收敛定理 MCT · Beppo Levi

L3
0 ≤ f1 ≤ f2 ≤ ⋯，fn → f 逐点 ∫fn dμ ↑ ∫f dμ（允许 +∞）

非负 + 单调升 ⟹ 极限与积分可交换。单调与收敛均可放宽到 a.e.。

把 (x, n) ↦ fn(x) 想成一族离散曲面：沿 n 方向的增量 fn+1 − fn ≥ 0 符号固定、且不依赖 x。

方向固定 ⟹ 总质量 ∫fn 是单调数列 ⟹ 必有极限；质量只能逐步堆积、无法在取极限时逃逸，逐点极限恰好接住全部质量。

注意：单调是你假设的，MCT 真正说的是回报——单调 ⟹ 可交换。

① ≤ 方向：积分单调性白送。
② ≥ 方向：任取简单函数 s ≤ f，固定 c∈(0,1)，令 En = {fn ≥ c·s} ↑ X；
③ ∫fn ≥ c∫Eₙs → c∫s（测度下连续性 → A1.4），对 s 取 sup、令 c→1 收尾。

级数版（Beppo Levi）：非负项可逐项积分 —— A1.5 Riesz–Fischer 的引擎（快速子列 + 2−k 估计）；下游接 Fubini–Tonelli、H4 蒙特卡洛方差分析。
